# Changelog

What changes in each version of Kayakoma Editor. The section of a version is also what the update window shows, so it is written for the people who use the app.

## 1.1.0

- **Find** menu in Edit: Find (Command-F), Find and Replace, Find Next and Previous (Command-G, Shift-Command-G), Use Selection for Find (Command-E).
- **Four new preview themes**: Slate, Lagoon, Coral and Typewriter.
- The line width setting has a last step, **Window**: the preview fills the whole window.
- **Updates**: the app now checks for new versions and installs them when you agree. See Settings > Updates.

## 1.0.0

- First release.
